# perishable-inventory-optimization
A repository containing the code used in my thesis 'Performance of Tabular Model-Free Reinforcement Learning Methods for Inventory Optimization Under Perishability'

To use each model, specify the parameter value in the main file (monte_carlo.py, qlearning.py, sarsa.py, value_iteration.py). Then specifcy the seeds and shelf_life values in the matching run file (run_mc.py, run_ql.py, run_sarsa.py, run_vi.py) Then run this file. The results will be saved as a JSON file.
